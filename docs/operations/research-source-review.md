# Free research source review — 2026-10-26

This review concerns public sources for the seven research categories. “Free” does not mean unlimited or permission to republish everything. The shared outbound policy remains closed by default, quota errors are hard stops, no paid fallback is permitted, and each provider remains blocked until its per-service terms, account-side cost exposure, rights, and quota are explicitly reviewed. No new provider was connected by this phase.

| Category | Reviewed source candidate | Cost, access, and limits | Rights and use boundary | Phase status |
|---|---|---|---|---|
| Finance | Federal Reserve official RSS/releases (existing) | Public RSS/HTTP; no API key or paid tier used by the current collector | Keep source URLs and excerpts; distinguish official announcement from independent analysis | Existing bounded collector remains enabled |
| Stocks | OpenDART corporate filings; SEC EDGAR public data APIs | OpenDART says service is generally free but requires an issued key, has published/account-specific quotas, and may change fees. The existing Wikidata connector remains limited to CC0 structured metadata for topic discovery; it does not approve the truth of a current corporate announcement, financial figure, business status, or product claim. Google Search Console remains an analysis source for already-published content only. It is not used as general web search-volume data. Search volume, competition, and CPC remain unset when no source supplies them.

## Official references

- [OpenDART terms](https://opendart.fss.or.kr/intro/terms.do) describe generally free service, the possibility of fees for some services, and changeable request allowances. [OpenDART usage guide](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DE005&apiId=AE00076) describes request-limit errors and account-specific restrictions.
- [SEC EDGAR API page](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) describes public filing/XBRL APIs without API keys. [SEC fair-access guidance](https://www.sec.gov/about/developer-resources) specifies moderated access and a maximum of 10 requests per second.
- [Korea Tourism Organization Tourism Information API record](https://www.data.go.kr/data/15101578/openapi.do?recommendDataYn=Y) lists no fee, a 1,000-call development allowance, production review, and restrictions for image assets. Locale-specific endpoints and image records need their own rights check.
- [Food Safety Korea API portal](https://www.foodsafetykorea.go.kr/api/main.do) requires registered API credentials and lists service change/restricted-operation notices; use must be checked against the exact dataset and current notice.
- [OpenDART corporate filings API](https://opendart.fss.or.kr/) requires an issued key. Account quota and changes must be reviewed before enabling any job.

These pages were reviewed on 2026-10-26. Re-check terms, quotas, commercial reuse, attribution, and account billing before enabling a source. No API request or credential registration was performed as part of this review.
