# P5-CODEX-032 — 자동 공개 게시 정책 초안 (비활성)

**상태: 제안만, 미승인·미적용.** 이 문서는 운영 정책 변경이나 Blogger 쓰기 승인이 아니다. 현재 `manual`, Auto OFF, 사람 검토 게이트 및 공개 쓰기 차단을 유지한다.

## 현재 영구 규칙과 충돌

현재 프로젝트 정책은 금융·정책 원고의 의미적 정확성, 자연스러움, 권리 및 편집 검토가 불확실하면 `quality_held`에 두고, 사람 편집 검토를 요구한다. exact-version publication approval은 공개 쓰기를 켜지 않는다. 따라서 매 원고 사람 검토 없이 전문가 칼럼을 공개하는 것은 현 정책상 허용되지 않는다. 이 제한을 없애려면 프로젝트 소유자가 정책 변경의 콘텐츠 범위, 대체 검증 기준, 책임 주체 및 롤백 조건을 별도로 승인해야 한다. 자동으로 승인 이벤트를 만들거나 기존 정책을 느슨하게 하지 않는다.

## 제안되는 최초 자동 대상

운영 정책 변경을 검토할 때 대상은 해석성 금융 칼럼이 아닌 **공식 발표의 제한적 사실 요약**으로 한정한다.

- 허용 후보: 한 개의 등록 언어·블로그에 대한 정부·중앙은행·통계기관의 당일 공식 발표 요약. 공식 원문의 재사용 조건이 확인되고 사실 문장이 원문에 직접 연결되는 유형.
- 계속 사람 검토: 투자 전망·추천, 정책 효과 예측, 복수 자료를 합성한 인과 주장, 제3자 기사/유료 자료, 권리 상태 불명, 번역·현지화, 출처 충돌, 중요 수치의 기간·단위가 모호한 원고.
- 모든 기사: 원문 문서 재확인, 주장·출처 연결, 발표일/기준기간, 링크/권리, 신선도, 중복, 대상 언어, SEO/HTML 안전, Blogger 응답/GET 확인. 실패·미측정은 게시 보류.
- 자동화는 허용량을 채우는 목표가 아니며 유효 원고가 없으면 0건.

이 좁은 후보 범위조차 현재의 필수 사람 편집 검토를 대체하지 않는다. 무인 게시를 실제 허용하려면 새 사용자 승인에서 해당 대체 정책을 명시적으로 승인하고, 코드의 분리된 정책 버전과 검증 경로를 구현한 뒤 격리 테스트와 승인된 Blogger 테스트를 통과해야 한다.

## 운영 상한 초안 확인값

사용자가 제공한 정책 초안은 KST 전역 50/일, ko 10/일, ja 10/일, zh-CN 5/일, en 전역 잔여 우선·20/시간, blog 최소 5분, 계정 쓰기 최소 2분이다. 이는 자체 상한이지 Google 보장 quota가 아니다. 운영 DB의 현재 설정은 global `manual`, `daily_auto_limit=1`, `minimum_interval_minutes=1440`, `operations_auto_approved=false`; 이 문서에서는 변경하지 않았다.

## 활성화 전 필수 승인 및 점검

1. 사람이 정책 버전과 허용 콘텐츠 유형을 명시적으로 승인한다.
2. 사람이 Blogger Cloud Billing/usage/quota 위험을 별도 확인하고 허용한다. 기존 비용 attestation은 이 검증을 대신하지 않는다.
3. ChatGPT Work 예약의 추가 사용량/credit 상태가 계정에 추가 비용 없이 동작하는지 운영자가 확인한다. 현재 프로젝트가 계정별 사용량을 확인할 수 없다.
4. 예약 실행 파일 전달이 실제 local project에서 성공했음을 검증한다.
5. 수신 원고는 승인된 대체 게이트를 통과해야 하며, import metadata만으로 publish 권한을 얻지 않는다.
6. Blogger API 쿼터/권한, 멱등성, remote GET, DB 원장, KST 집계, emergency stop, 복구를 다시 검증한다.
7. 승인은 승인된 버전·해시·블로그·게시 범위와 정책 버전에 한정한다. 범위를 넘는 Auto는 중지한다.
