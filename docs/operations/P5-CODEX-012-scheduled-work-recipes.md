# P5-CODEX-012 — Scheduled Work 복사-사용 레시피

이 문서는 예약 작업을 설정하는 사람이 ChatGPT의 Scheduled 화면에 옮길 초안이다. 프로젝트는 예약 작업을 만들거나 상태를 읽지 않는다. 예약 작업 결과도 검증된 출처로 간주하지 않는다. 2026-10-29 공식 안내 기준 Plus 활성 작업 한도 5개와 동일한 수이므로, 등록 전에 기존 활성 작업을 확인한다.

## 공통 안전 규칙

각 작업은 한 번 실행할 때 적격 기사 0~1건만 작성한다. 확인할 가치가 없거나 근거가 부족하면 콘텐츠 Import JSON을 만들지 말고 사유만 보고한다. 예약 작업 출력은 대화 결과일 뿐, `.local/gpt-scheduled-import/ready/`에 자동 전달됐다고 간주하지 않는다.

시세·수치·거래일은 공식 거래소/지수 원천 또는 명시적으로 사용 허가가 확인된 원천에서 확인한다. 값에는 원천, 기준 시장일, 발표·조회 시각, 통화/단위, 지연 여부를 붙인다. 거래소 달력에서 거래일·휴장·조기 폐장을 확인하지 못하거나 확정 종가/공식 기준값을 찾지 못하면 결과 파일을 만들지 않는다. 평일이라는 이유로 거래일을 추정하지 않는다. 과거 마감값을 오늘 값처럼 쓰지 않는다. 사용자에게 제공할 권리가 불명확한 시세 데이터는 인용·복제하지 않는다.

글은 지정 언어로 독립 작성한다. 다른 언어 원고를 복사·번역하지 않는다. 모든 중요 사실은 제공된 원문 출처와 주장 연결을 가져야 한다. 해당 지역 독자에게 관련 없는 주제, 근거 없는 전망/투자 조언, 검색량이나 순위의 추정, 내부 UUID·FACT 식별자는 기사에 넣지 않는다. 명목/실질 수치, 발표일/기준기간, 사실/해석을 구분한다. JSON은 Content Import 1.0 및 Scheduled Envelope 1.0 스키마와 정확히 일치해야 한다. 자기 보고한 작업 ID, 검증 결과 또는 예약 실행을 외부에서 확인된 사실로 주장하지 않는다. Import는 사람 검토 대기이며 자동 발행을 허용하지 않는다.

예약 작업은 ChatGPT에서 결과를 만들 수 있어도 로컬 파일 쓰기를 보장하지 않는다. 파일을 생성·저장할 수 없는 경우 JSON을 결과로 제시하고, 운영자가 스키마 검증 후 파일을 `.part`로 저장해 같은 폴더에서 `.ready.json`으로 원자적 이름 변경을 수행한다. 외부 예약 작업 상태가 보이지 않으면 수동 Import를 사용한다.

## 1. 한국 시장 마감 — `market-close-kr`

- 대상 시각 초안: 한국 거래일 16:30 Asia/Seoul. 거래소의 당일 일정으로 조기 폐장 여부를 확인한다.
- 독립 작성 언어/대상: 한국어 / 등록된 ko Blog ID·URL.
- 원천 확인 범위: KOSPI·KOSDAQ의 공식 종가 및 등락률, 제공이 허용된 시장 통계. 각 수치는 기준일·원천·단위를 명시한다.
- 중단 조건: 공식 달력·종가·이용 권리 중 하나라도 확인 불가하면 원고/Import 생성을 생략한다.

## 2. 일본 시장 마감 — `market-close-jp`

- 대상 시각 초안: 일본 거래일 16:30 Asia/Seoul. 일본 거래소 공식 휴장/조기 폐장 일정을 먼저 확인한다.
- 독립 작성 언어/대상: 자연스러운 일본어 / 등록된 ja Blog ID·URL.
- 원천 확인 범위: Nikkei 225·TOPIX의 공식 기준값 및 허용된 거래 통계. 지수 제공자와 거래소를 동일 출처로 취급하지 않는다.
- 중단 조건: 해당 지수의 공식 값 또는 재사용 권리가 불분명하면 생략한다.

## 3. 중국 시장 마감 — `market-close-cn`

- 대상 시각 초안: 중국 거래일 17:00 Asia/Shanghai의 장 종료와 공개 지연을 감안한다. 상하이·선전 거래소 달력과 세션을 각각 확인한다.
- 독립 작성 언어/대상: 중국어 간체 / 등록된 zh-CN Blog ID·URL.
- 원천 확인 범위: 상하이·선전의 정확한 공식 지수 명칭과 거래일 종가. 정책 자료는 시장 데이터와 별도 주장으로 연결한다.
- 중단 조건: 대만·홍콩 자료를 중국 본토 시장 데이터 또는 본토 독자 관련성의 대체 근거로 사용하지 않는다. 공식 지표와 권리가 확인되지 않으면 생략한다.

## 4. 미국 시장 마감 — `market-close-us`

- 대상 시각 초안: 미국 정규장 마감 후 다음 날 08:30 Asia/Seoul을 기준으로 하되, 미국 거래소 공식 일정과 America/New_York의 DST를 적용해 실제 대상 세션을 식별한다.
- 독립 작성 언어/대상: 자연스러운 영어 / 등록된 en Blog ID·URL.
- 원천 확인 범위: S&P 500, Nasdaq Composite(또는 데이터가 명시한 Nasdaq 지수), Dow Jones Industrial Average의 기준일 종가 및 등락률. 출처가 제공한 지수 정의를 바꾸지 않는다.
- 중단 조건: 조기 폐장·휴장·최종 값 공개 지연 시 확정 종가가 확인될 때까지 파일 생성을 보류한다.

## 5. 주간 금융자료 — `weekly-finance`

- 대상 시각 초안: 금요일 17:30 Asia/Seoul. Fed·SEC 등 허용목록의 신규 공식 문서를 검토한다.
- 산출: 한 주에 의미 있는 자료가 없으면 0건, 있으면 가치·최신성·중복·권리·독자 관련성 검토를 통과한 1~3개까지. 각 기사는 해당 독자에게 가장 관련 있는 한 언어로 독립 작성한다.
- Fed/SEC RSS 및 자료는 기존 허용 범위만 사용한다. 일반 URL 검색, 비허용 첨부 파일, 대량 자료 다운로드로 범위를 넓히지 않는다.
- 중단 조건: 신규성, 공식 원문, 사실과 출처 연결 또는 사용 조건을 검증하지 못하면 생략한다. 한 주제의 다국어 복제는 별도의 독자 가치가 증명되지 않으면 하지 않는다.

## 원고가 생성되지 않는 현재 제약

프로젝트 운영용 생성 Provider가 연결돼 있지 않다. 위 예약 작업이 외부 계정에서 글을 써도 프로젝트의 Research Package 검증기, SEO/HTML 검사 및 사람 검토를 자동 통과시키지 않는다. 프로젝트 내 원고 수신은 사용자가 결과 파일을 로컬 inbox에 둔 뒤 실행하는 `scripts/import-scheduled-content.py`로만 검증 가능하다. 이번 단계에서는 그 CLI를 실행하지 않았다.

Google Trends 6개 지역의 시간별 수집과 시간당 전체 원고 후보 상한 4건은 별도 로컬 스케줄러 구현이 필요하다. 현행 Trends 저장 계층의 12회/시간 API 상한을 원고 후보 상한으로 혼동하지 않는다. 마감 기사에 필요한 네 시장의 공식 가격·거래 달력·재배포 권리 adapter도 별도 검토 전까지 미연결이다.
