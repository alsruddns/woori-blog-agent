# P5-AI-001 — Research Package 모델 원고 비교 사전검증

## 결과 상태

**부분 완료 — 자료·권리·최신성 검토 완료, 실제 모델 원고 비교는 실행 전 차단됨.** Qwen3와 NVIDIA Build의 결과물을 만들지 않았으며 품질 비교 점수도 생성하지 않았다. 평가 완료나 콘텐츠 승인으로 표시하지 않는다.

## 목표와 기존 상태

기존 P5-CONTENT-002 패키지 `de118f17-ab50-46b7-b99f-4aba51f240ce` (`國軍加薪`, v1)를 사용해 동일한 검증 사실로 Qwen3 로컬 모델과 NVIDIA Build의 평가 원고를 비교하는 작업이다. 패키지 SHA-256은 `81bb85afa4e7d0d3ce2de03d6a5ed06268ff0ba770ad34aba703334c14ca0676`이다.

작업 시작 시 DB에서 다시 확인한 상태는 출처 3건, 기계적으로 출처 구간 연결이 된 사실 8건, 상태 `evidence_collected_pending_human_review`, `generation_ready=false`, `publish_ready=false`였다. 저장된 `independent_source_count=0`은 수정하지 않았다.

## 자료 검토

행정원 자료 두 건은 같은 발신기관의 정책 발표와 추가예산 설명이다. 서로를 독립 출처로 세지 않았다. 입법원 예산센터 자료는 별도 기관의 예산·절차 분석으로 독립적인 비판 관점을 제공하지만, 행정원 발표와 별도로 실제 급여 지급 또는 시행을 확인하는 자료는 아니다. 따라서 패키지의 사람 검토 전 독립 출처 수를 자동 변경하지 않았다.

기존 8개 fact excerpt의 직접 근거를 대조했다. 해석 시 지켜야 할 구분은 다음과 같다.

- NT$607.6 billion은 2026년 추가경정예산안의 전체 세출 규모다. 처우 조정 예산은 그 안의 NT$10.7 billion이다.
- NT$2,000은 특정 전문수당과主管職務加給 각각에 대한 제안이며 보편적인 기본급 인상액이라는 뜻이 아니다.
- 2026년 7월 1일은 해당 수당 인상분에 대해 행정원이 제시한 소급 적용일과 예산 절차다. 이를 실제 지급 완료로 표현할 근거는 확인되지 않았다.
- 일반 4% 조정은 2027년도 예산 편성 절차에 포함한다는 계획이며, 시행·지급 완료를 뜻하지 않는다.
- 9.98%~5.88% 예시는 일반 행정직 공무원의 직급별 사례다. 군인 인상률로 귀속하지 않는다.
- 입법원 예산센터의 법제·절차 지적은 해당 기관의 평가로 귀속한다. 최종 사법 판단으로 바꾸지 않는다.

최신성 확인을 위해 2026-10-28 입법원 안건 진행 페이지도 확인했다. 공개 진행 정보에는 `排入院會` 및 10월 2일·6일·13일 일정이 표시되어 최종 통과 사실을 확인하지 못했다. 행정원 제4023차 회의 자료(2026-10-01)는 후속 행정절차를 위해 추가예산안의 11월 말 전 삼독 통과를 요청한다. 이는 그 발언 당시 심의 중임을 보여 주지만 이후 통과 여부나 지급 여부를 확인하지 않으므로 두 항목 모두 원고의 불확실성으로 남긴다.

세 행정기관 자료의 재사용 고지는 출처 표시 재사용을 허용하되 제3자 저작물과 별도 제한 자료를 예외로 둔다. 각 문서 내 예외가 제거되었다고 확인할 수 없어 사람의 권리 검토가 남아 있다. 특히 NVIDIA hosted endpoint로 사실 발췌를 전송하려면 제공자 약관에 따른 사용자 자료 라이선스도 수반되므로, 자동 전송하지 않았다.

원문은 번체 중국어(zh-TW)다. 중국어 간체 결과물이 생성되지 않았으므로 번체-간체 의미·고유명사 검증은 미실행이다. 평가 시도 언어는 `zh-CN` 하나로 제한할 계획이었으며 다른 언어로 확장하지 않았다.

## 모델·비용 사전검증

로컬 설정에서 설치 모델은 `Qwen3-4B-Q4_K_M.gguf`, llama.cpp b11889 Vulkan 서버 PID 39500이며 loopback health 요청은 HTTP 200이었다. 다만 평가 DB의 시스템 CPU 상한은 80%인데 측정값이 100%였다. RAM 여유는 11.99 GiB, 디스크 여유는 172.22 GiB였지만 CPU 게이트 하나만으로 실행이 금지된다. 여러 `node.exe` 프로세스가 CPU를 점유했으나 소유 프로젝트를 확인·종료하지 않았다. 실제 추론은 0회이며 토큰·속도·추론 중 GPU 사용량은 미측정이다.

NVIDIA 공식 NIM 문서는 Developer Program 회원의 hosted endpoint 프로토타입·평가용 무료 접근을 안내한다. 다만 현재 모델별 rate limit은 계정 화면에서 확인하도록 안내되어 공개된 공통 무료 한도를 검증할 수 없다. API Trial Terms는 제한된 trial과 credits/instance limits를 두고, credits를 소진하면 이후 사용에 별도 subscription이 필요하다고 명시한다. 그러므로 프로젝트의 “무료 한도 도달 시 중단, 유료 전환 금지” 정책에서는 사용자 계정별 남은 용량과 선택 모델 상한을 확인하지 않은 요청을 허용할 수 없다. 이 저장소의 `woori.external_policy`에도 NVIDIA provider가 등록되지 않았다. 키 존재는 permission으로 간주하지 않으며, 인증 설정 값은 읽거나 출력하지 않았다.

Trial terms는 서비스 제공 과정에서 사용자 콘텐츠를 처리하는 권한과 보안·남용 감시 및 제품/모델 개선 관련 수집을 설명한다. 공개 정부 사실이라도 출처별 재사용 예외 검토가 남아 있어, 이번에는 사실 패키지를 hosted endpoint에 보내지 않았다. 이에 따라 NVIDIA Build 모델 선택, account quota 확인, 이용 조건 확인은 not verified다. 로컬의 일반 유료·기타 외부 API 게이트에는 변경이 없다.

## 실행 결과와 감사

- Qwen3: 모델 설치 및 health 확인, 추론 시작 전 CPU 게이트 차단, 호출 0, 기사 미생성.
- NVIDIA Build: provider allowlist·모델별 무료 quota/계정 접근을 확인할 수 없어 요청 0, 기사 미생성.
- 동일 입력 A/B 원고, 사실 정확도·분석 깊이·문장 자연스러움 비교: 수행하지 않음.
- 모델/외부/Blogger 호출: 각각 0회.
- DB 변경: 평가 DB `woori_blog_agent_eval`의 append-only `evaluation.package.comparison.preflight_blocked` 이벤트 1건(ID 85085)만 추가. 운영 DB 및 테스트 DB에는 쓰지 않았다.
- 콘텐츠 상태: `generation_ready=false`, `publish_ready=false` 유지.

## NVIDIA 비용 정책 레지스터

`docs/operations/zero-cost-policy.md`에 NVIDIA NIM hosted endpoint를 “blocked and not allowlisted”로 기록했다. 문서에는 무료 평가 범위, 계정별 공개되지 않은 한도, trial 이후 subscription 조건, 평가 전용 범위, 제출 콘텐츠 처리 내용을 적었다. 어떠한 NVIDIA runtime route나 paid fallback은 구현하지 않았다.

## 승인·조건이 확인된 뒤 재개할 때

1. 사용 중인 다른 프로세스를 종료하지 않고, 시스템 CPU가 80% 미만으로 내려간 상태에서 평가 자원 게이트를 다시 확인한다.
2. NVIDIA 계정에서 선택 모델의 무료 잔여 사용량/제한을 확인하고, 초과 시 요청이 실패로 닫히며 자동 유료 전환되지 않는지 계정 상태에서 확인한다.
3. 외부 제공자 추가는 별도 비용·데이터 처리 검토와 허용목록 구현/테스트가 필요하다. 정부 소스별 재사용 예외도 사람 검토한다.
4. 두 조건이 준비되면 동일한 8개 사실 원장, 동일한 zh-CN 프롬프트와 출력 제약으로 각 모델을 각각 한 번만 평가한다. 결과는 별도 평가 아티팩트로 보존하고, 품질 부족은 사람 검토 대기 상태로 둔다.
