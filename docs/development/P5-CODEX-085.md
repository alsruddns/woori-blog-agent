# P5-CODEX-085 — Trends 선정 및 발행 UI 회귀 (부분 완료)

- 2026-10-30 KST, develop. P5-CODEX-084 미실행, 요구사항 P5-CODEX-085로 통합.
- 현재 11개 지역과 RSS 5분 전역 간격 및 시간당 12회 상한은 기존 zero-cost-policy와 외부 호출 게이트의 명시적 제한이다. 11개 지역을 매 10분마다 각각 수집하면 시간당 66회가 되어 상한과 양립하지 않는다. 제한을 우회하지 않았고 실제 10분 11지역 수집은 미구현이다.
- Google 공식 도움말은 4·24·48시간 및 7일 범위와 약 10분 갱신을 설명한다. RSS의 hours 소수값에 대한 공식 의미는 확인하지 못했으며 기존 허용 경로 외의 원격 요청은 실행하지 않았다. 0.1 등의 실제 HTTP와 필터 유효성은 미검증이다.
- 선정된 같은 지역의 현재 회차 후보를 원본 검색량 하한 내림차순, 동률 시작 시각 내림차순으로 조회한다. 검색량 또는 실제 시작 시각이 없거나 최근 10분 범위 밖이면 자동 큐에서 제외한다. 국가 간 검색량은 비교하지 않는다. 뉴스 URL이 없더라도 구체적인 분야 주제는 독립 Codex 조사 후보로 허용하되 뉴스 불일치·소문은 보류 또는 폐기한다. 이는 사실·권리 검증이나 발행 승인이 아니다. 현재 기존 시간당 하나의 Codex 작업 한도는 유지한다.
