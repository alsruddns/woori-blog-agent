# P3-9U-001 - Direct Source Overlap Analysis and Generation Improvement

- Work ID: P3-9U-001
- Work date: 2026-10-27 (Asia/Seoul)
- Reason: The Phase 3.9-T Fed English draft was held by the direct-source-overlap rule.
- Before: The draft had a 30-token contiguous overlap. The quality check ran only after article composition; the faithful-paraphrase prompt did not explicitly prohibit long source wording. Its full title-like topic was also reused as a keyword.
- Goal: Identify whether the overlap was a detector false positive, prevent copied source sentences earlier, and avoid turning an overlong source label into SEO metadata.

## Evidence and analysis

The saved source version and content version were read without changing either. `longest_source_overlap` measures the longest contiguous normalized token run from one source excerpt; it does not add separate matches across the article. The 30-token match was the complete sentence describing how the Board's discount-rate setting process differs from the FOMC's federal-funds target-range process. The section-generation model reproduced that sentence verbatim. This is a genuine source-copying failure, not a summed-token or proper-name-only false positive. The original 25-token gate remains unchanged.

The original saved version remains `quality_held` and `publish_ready=false`. Two append-only deterministic rechecks were added to the isolated evaluation database. Both retained the same 30-token overlap. They also exposed `keyword_list_is_bounded_and_unique`: the saved search keyword was a long topic label containing the dated meeting list. The latest recheck event is recorded in [the analysis artifact](P3-9U-overlap-analysis.json). The rechecks used zero model calls and did not overwrite source, content, or earlier evaluation records.

## Changes

- Strengthen the local faithful-paraphrase instruction to require independently worded prose and avoid long source runs while preserving names and values.
- Apply the existing 25-token direct-overlap limit to each localized fact before it can be treated as machine-passed. The final article gate remains in force as well.
- Derive a bounded search-intent phrase by removing a clearly dated qualifier from a long topic label. If the remaining phrase is still over 80 characters, stop and hold for review rather than truncate it arbitrarily.
- Keep human semantic review, naturalness, source-rights review, and `publish_ready=false` separate from these deterministic checks.

Actual AI regeneration is deferred to Phase 3.9-V so the remaining per-language quota is preserved for its ordered evaluation. Therefore, the prompt change is implemented but real quality improvement is not yet verified.
