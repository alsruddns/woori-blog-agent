- **Work ID:** P5-CODEX-162
- **Work time:** 2026-11-18, Asia/Seoul

- **Existing problem:** Publication controls were already enabled at revision 29 and the Publication Worker was healthy in `scheduled-auto-manual-trends` mode, but recent Trends authoring attempts failed strict body validation with `trend_factual_paragraph_citation_required`. Startup does not mutate persisted controls or create new policy events. The existing login task still targets `start-services.ps1`, so its no-argument launch uses the updated default. Existing historical failed authoring jobs remain held and are not retried or reauthorized.
