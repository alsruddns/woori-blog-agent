- 작업 일시: 2026-10-26 16:20 KST
- 변경 사유: Phase 3.7 실원고 4개 언어가 모두 `quality_held`였고, 섹션 통과 후 최종 판정에서 생성 오류와 규칙 오탐을 구분할 필요가 있었다.
- 기존 상태: Federal Reserve Board 공식 자료 1건, 근거 문장 4개로 Qwen3 4B Q4_K_M을 실행했다. 생성 기록·버전·기존 감사 이벤트는 읽기 전용으로 분석했다.
- 변경 목적: 보수적 품질 게이트를 유지하면서 확인된 오탐을 수정하고, 사실을 고정한 템플릿 방식을 기존 AI 생성 방식과 비교한다.

네 언어 모두 저장된 AI 응답은 Draft JSON 스키마로 파싱되었다. 저장 실행의 섹션별 자원 지표는 빈 값이어서 이번 보고에서 추정하지 않는다. 원래 최종 SEO 감사에서는 `## 1` 등 구조용 번호, 현지 날짜, 제목 키워드 및 고유명사 검사 등이 함께 실패했다. `## 1`은 섹션 검사에서는 처리되었으나 전체 원고 검사에서는 사실 숫자로 집계됐다.

실제 오류와 오탐을 분리했다.

- 오탐 수정: 번호만 있는 Markdown 제목은 숫자 사실 비교에서 제외한다. 한국어·중국어·일본어 날짜는 `YYYY-MM-DD` 형태로 정규화한다. 인용 표식은 반복 문장 비교에서 제거한다. 일반 Markdown 제목만 본문 검사에서 제외하고, 모델이 인용된 사실 문장에 `##`를 붙인 경우에는 그 사실 문장을 검사한다.
- 오탐 수정: `Federal Reserve Board Announces` 및 `Enforcement Actions` 같은 제목 표현을 고유명사로 취급하지 않고, 출처에 있는 공식 명칭의 부분 표현과 소유격을 허용한다. 근거에 없는 다른 기관명은 계속 실패한다.
- 실제 문제 유지: 영어 원고에는 근거가 말하지 않은 “추가 조치가 없을 것” 및 감독 목적 달성에 대한 추정이 반복되었다. 재평가에서도 같은 문장 반복과 검색 키워드 구조 검사가 실패했다. 고유명사와 숫자 오탐을 고쳐도 의미상 사실 검증을 통과한 것으로 처리하지 않는다.
- 번역 검토: 한국어·중국어·일본어 원고에서 고유명사가 번역·음역된 경우 규칙기가 원문 이름 보존을 판정할 수 없다. 운영 승인이 아니라 사람의 원문 대조가 필요하다.

## A/B 비교

두 방식은 동일한 Phase 3.7 실행, Federal Reserve 자료 1건, 근거 ID 및 언어별 검색 프로필을 사용했다. A는 저장된 실제 Qwen3 4B Q4_K_M 실행 결과를 새 규칙으로 재평가했다. B는 검증된 자료 문장을 인용과 함께 그대로 렌더링하는 실험용 결정론 템플릿이며 AI 호출을 하지 않는다. 따라서 B의 시간은 로컬 렌더링 시간이지 AI 추론 속도가 아니다.

| 언어 | 방식 | 소요 시간 | 모델 호출 | JSON/Draft 스키마 | 인용·근거 검사 | 규칙 기반 최종 게이트 |
| --- | --- | ---: | ---: | --- | --- | --- |
| en | A: 기존 AI | 149,970 ms | 5 | 성공 | 출처 ID와 사실 문단 인용 검사 통과 | 실패: 반복 문장, 검색 키워드 구조 |
| en | B: 근거 템플릿 | 1 ms | 0 | 성공 | 전부 통과 | 통과; 사람 검토는 여전히 필요 |
| ko | A: 기존 AI | 327,995 ms | 6 | 성공 | 인용 검사 통과 | 실패: 고유명사·언어 메타데이터, 검색 키워드 구조 |
| ko | B: 근거 템플릿 | 2 ms | 0 | 성공 | 전부 통과 | 실패: 본문에 원문 영어를 보존해 언어 일치 검사 실패 |

B 영어 원고는 검사 가능한 사실 범위와 출처 연결에서 개선됐지만, 이 단일 출처 실험만으로 모델이나 운영 품질을 선정하지 않는다. 한국어 템플릿은 사실을 번역하지 않기 때문에 언어 게이트를 통과하지 못한다. 중국어·일본어 템플릿 비교는 확장하지 않았다. 한국어에서도 현지화가 해결되지 않았으므로 같은 원문 인용 방식을 추가 언어에 적용해도 결과가 유효하지 않다.

모델 비교는 기존에 측정된 Qwen3 4B Q4_K_M 실제 실행 결과를 기준으로 삼았다. 이번 작업 시 로컬 llama.cpp 서버가 중지되어 있어 새 추론은 실행하지 않았다. 새 모델을 다운로드하거나 외부/유료 API를 호출하지 않았다. 이번 템플릿 A/B에서는 CPU·RAM·GPU를 새로 측정하지 않았다.

## 구현 및 데이터 보존

- `grounding.py`: 숫자·날짜, 인용이 붙은 Markdown 본문, 고유명사, 반복 문장 검증을 보완했다.
- `evidence_template.py`: 출처 문장을 변형 없이 인용하는 실험용 템플릿을 추가했다. 근거가 없으면 생성을 거부한다.
- `scripts/015_research_experiment_evaluations.sql`: 수정·삭제·truncate를 거부하는 append-only 비교 평가 테이블을 추가했다.
- `scripts/evaluate_evidence_template.py`: 이전 실행을 변경하지 않고 새 A/B 평가 행과 감사 이벤트를 추가한다. 재평가 결과는 experiment ID `364f08b9-9e1b-4582-bfa9-31c8336ab3dd`에 저장했다.
- `/admin/research/state`와 `/research`: 비교 결과, 실패 유형별 건수, 근거 연결, 처리 시간·호출, 검토 대기 및 원고를 표시한다.
- 재검증 경로는 새 SEO 감사 행의 `passed`를 실제 grounding 결과와 일치시킨다. 기존 감사 행은 변경하지 않았다.
- 발행 준비 `false`, 사람 검토 필요, Blogger 실제 쓰기 차단, 유료 AI·서비스 차단 상태를 유지했다.

## 검증 결과 및 남은 문제

- 검증: Python 테스트 91개 통과, Ruff 통과, mypy 통과(22개 소스 파일), compileall 통과, Next.js lint/typecheck/build 통과.
- PostgreSQL 마이그레이션 015 적용 및 재실행 확인. API state 함수에서 실험 이력 36행을 조회했고, 감사 이벤트 36건을 확인했다. 최신 평가 묶음은 4개 언어의 기존 AI와 영어·한국어 템플릿 비교 6행이다. 앱 계정의 평가 행 UPDATE는 권한으로 차단됐다.
- 실제 AI 추론은 이번 단계에서 재실행하지 않았다. A 결과는 과거 실제 Qwen3 4B 호출을 저장본으로 재평가했고, B는 AI 미사용 실험이다.
- 한 건의 공식 자료로는 금융 원고의 주장을 충분히 검증할 수 없다. 영어 템플릿의 자동 규칙 통과는 사람에 의한 사실·자연스러움 승인과 별개다.
- 과거 모델 실행의 섹션 리소스 지표가 비어 있고, 원고의 의미적 주장 검증은 아직 사람 검토가 필요하다.
- `main` 병합 및 Blogger 게시·수정·삭제는 수행하지 않았다.

- 수정 전 상태: 기존 4개 원고와 감사 기록만 존재했고, 생성 방식 비교 및 비교 평가 이력 테이블은 없었다.
- 수정 후 상태: 기존 기록은 그대로 보존되고, 규칙 회귀 테스트와 템플릿 비교 행이 새로운 append-only 이력으로 추가됐다.
- 테스트 결과: 위 자동 검증 전부 통과. append-only 평가 기록과 감사 이벤트는 새 이력으로만 추가했다.
