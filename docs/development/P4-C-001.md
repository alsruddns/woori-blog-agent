## 구현

- `/research`에 Fed EN/KO/JA/zh-CN 원고 검토 영역을 추가했다. 제목·키워드·전체 원고·문장별(문단 출처 표식 적용) 출처·근거 원문·근거 숫자/날짜·고유명사 후보·기계 검사 결과를 표시한다.
- 검토 의견, 사실 정확성, 번역 자연스러움, 독자 가치, 수정 요청 및 과거 검토 이력을 저장할 API를 추가했다. 검토 결과는 출판 승인과 분리되고 기존 버전·품질 결과를 수정하지 않는다.
- 운영 DB migration 027에 `article_human_reviews` append-only 테이블과 감사 이벤트를 추가했다. 수정·삭제·truncate 차단 트리거를 적용했다.
- 평가 전용 DB `woori_blog_agent_eval`의 `woori_eval_reader`에는 검토 대상 레코드 조회를 위한 `article_quality_evaluations`의 SELECT만 추가했다. reader의 쓰기 권한은 변경하지 않았다. 권한 추가는 `evaluation.reader_access.granted` 이벤트로 기록했다.
- `/research`에서 SEC 기존 평가 이력, KST quota, Blogger OAuth/URL/Blog ID/과거 읽기 검증 기록, 발행 안전 집계 및 미검증 항목을 표시한다.
- live Blogger 검증 스크립트가 zero-cost 정책 차단을 비밀정보나 stack trace 없이 보고하도록 수정했다.

## 실제 데이터 및 실행 결과

- Fed 검토 대상: 4개 (언어별 1개), 각 원고의 사실 5개와 승인된 Federal Reserve 출처 1개가 API 상태 응답에서 확인됐다. 4개 모두 machine pass이며 사람 검토 이력은 0건이다. 사람 검토는 이 작업에서 수행하지 않았다.
- SEC 신규 추론: 실행 0건. 격리 DB와 실행 자원은 준비됐지만 순서상 첫 EN quota가 2/2여서 모델을 시작하지 않았다. 기존 SEC Apple 10-Q 평가는 과거 기록으로만 표시하고 신규 Phase 4-C 결과와 합산하지 않았다.
- Blogger OAuth: 실제 운영 DB에 연결 계정 1개, Blogger readonly scope 및 요청한 4개 URL/Blog ID 매핑이 확인됐다. 현재 DB의 과거 성공 읽기 검증은 2026-10-26에 기록되어 있고 각 블로그는 게시글 0개, 1페이지 종료, 계정 접근 성공이었다.
- 이번 Phase의 Blogger API GET: 0건. 실행 시도는 공통 external gate에서 `provider_cost_unverified`/수동 zero-cost 검토 필요로 차단됐고 HTTP 전송 전에 종료했다. 따라서 이번 Phase의 Blog ID 재검증, 게시글 상세 조회, 페이지네이션(두 번째 페이지 이상), 토큰 갱신 동작은 미검증이다. 기존 OAuth/읽기 기록은 이번 실조회로 간주하지 않는다.
- 현재 API 매핑은 4개 언어 모두 지정 URL과 일치하고 OAuth scope는 Blogger readonly다. 기존 성공 감사는 blog당 posts=0/pages=1/terminal_page=true였으므로 상세 게시글 및 두 번째 페이지는 당시에도 확인 대상이 없었다.

- 실제 모델 호출 0회, 유료 API 호출 0회, Blogger 쓰기 0건, 운영 게시글 변경 0건, 신규 `publish_ready=true` 0건. 평가 quota는 변경하거나 초기화하지 않았다.

## 남은 문제

- SEC C3 실제 다국어 추론은 EN quota가 KST 다음 일일 구간에서 허용될 때 다시 실행 가능하다. 본 기록은 자동 대기/재실행하지 않는다.
- Blogger API 비용 근거 검토가 완료되지 않아 실제 GET 동기화는 차단 상태다. Google Cloud 프로젝트의 과금 설정은 로컬 앱에서 확인할 수 없다.
- 기존 Blogger 성공 검증에서 블로그당 게시물이 0개였으므로 게시글 상세 및 2페이지 이상 페이지네이션은 확인할 대상이 없었다.
- Fed의 의미 정확성, 번역 자연스러움, 독자 가치에 대한 사람 검토는 아직 수행되지 않았다.
- 커밋 해시와 원격 푸시 결과: 최종 기록 예정.
