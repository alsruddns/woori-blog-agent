## Findings and implementation

Fed Korean generation was marked held because `proper_names()` missed exact Latin organization names when Korean particles were attached (`Federal Reserve Board?`, `Federal Open Market Committee?`). Python Unicode word boundaries treat Hangul as a word character, causing a checker false positive. The body contains both required names, and localized per-fact checks had already preserved them. Replaced Unicode `\b` with ASCII-name-character lookarounds so exact name matching remains strict while adjacent Korean particles are accepted. Added a regression test that also ensures unsupported organizations remain out of the detected set.

The existing Korean draft was not edited or regenerated. A deterministic recheck created a new append-only evaluation and audit event and passed. The original generation artifact still records its original held result.
