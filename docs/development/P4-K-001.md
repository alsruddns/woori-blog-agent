## 모델 및 라이선스

후보는 `bartowski/Qwen_Qwen3-4B-Instruct-2507-GGUF` revision `ae44f08e1392f39c0e474af10c3ff8355c8b6688`, 파일 `Qwen_Qwen3-4B-Instruct-2507-Q4_K_M.gguf`, 크기 2,497,280,736 bytes, SHA-256 `2fde00ce69dd4899c70d020845e2638353015bba0fdf161b3eb965f2bca4464e`이다. upstream Qwen 모델 카드는 Apache-2.0을 표시한다. GGUF 저장소에는 별도 라이선스 메타데이터가 없어 upstream 근거를 명시하고 로컬 평가만 수행했으며 재배포하지 않는다. 설치 전 디스크 여유와 공개 고정 revision의 SHA·크기를 확인했다.

Gemma 3 4B는 Google 별도 이용 약관 및 Hugging Face 접근 조건을 확인했으나 약관 수락·다운로드·실행은 하지 않았다. 추가 후보를 무조건 설치하지 않는 범위 선택이다.

공식 근거: [Qwen 모델 카드](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507), [고정 GGUF 파일 메타데이터](https://huggingface.co/bartowski/Qwen_Qwen3-4B-Instruct-2507-GGUF/blob/main/Qwen_Qwen3-4B-Instruct-2507-Q4_K_M.gguf), [Gemma 이용 약관](https://ai.google.dev/gemma/terms), [Gemma 모델 접근 조건](https://huggingface.co/google/gemma-3-4b-it).

## 실제 평가 결과

Qwen3 Instruct-2507 후보로 실제 추론 4건을 수행했다. 비교 데이터는 동일 Fed/SEC source ID와 C3 파이프라인·기계 게이트의 기존 저장 실행을 사용했다. 같은 실행 시각·입출력은 아니므로 속도 비교는 참고값이며, 모델 전체 성능의 통계적 결론으로 취급하지 않는다.

| 주제 / 언어 | 후보 기계 게이트 | 호출 / 토큰 | 전체 시간 | 평균 생성 속도 | 피크 RSS | 판정 |
|---|---:|---:|---:|---:|---:|---|
| Fed / en | 실패: `no_mass_direct_quote` (겹침 28단어) | 5 / 205 | 33.08초 | 7.43 tok/s | 3479.35 MiB | quality_held |
| SEC / en | 통과 | 4 / 193 | 23.68초 | 9.80 tok/s | 3527.60 MiB | quality_held, 사람 검토 필요 |
| SEC / ko | 실패: 언어 혼입, 숫자 보존, 미승인 명칭·수치 | 5 / 244 | 31.40초 | 8.92 tok/s | 3632.96 MiB | quality_held |
| SEC / ja | 실패: 언어·숫자·미승인 명칭 | 5 / 234 | 27.75초 | 9.79 tok/s | 3707.12 MiB | quality_held |

CPU 샘플은 실행별 결과 JSON에 보존했다. llama.cpp server에서 GPU 엔진 사용률 샘플이 관측된 실행은 결과 JSON에 남겼다. 단일 통합 CPU/RAM/GPU 비교값으로 환산하지 않았다. 전체 4개 언어 후보 평가를 마치지 않았다. 한국어·일본어에서 같은 사실/언어 오류가 연속 확인된 뒤 추론을 중단해 추가 비용성 호출과 무의미한 반복을 막았다. zh-CN 후보 및 Fed의 비영어 후보는 미실행이다.

기준 Qwen 저장 결과와 비교할 때 SEC 영어는 양쪽에서 기계 검사 통과했으며 후보의 단일 관측 속도만으로 개선이라 단정하지 않는다. 후보 Fed 영어는 기준 저장본의 source-overlap 17단어보다 큰 28단어 겹침으로 실패했다. 후보 SEC 한국어·일본어는 숫자·명칭·언어 검사에서 보류되었다. 그러므로 후보는 운영 모델로 승격하지 않는다. 기존 기준 모델을 운영 기본값으로 유지한다.

기준 모델로 Fed 영어를 새로 재실행한 시도는 실제 모델 5회 호출, 198 completion tokens, 23.887초 추론 후 기존 내용 중복으로 거부되었다. 중복 방지 게이트를 우회하지 않았고 새 초안을 저장하지 않았다. 원본 결과 산출물에 해당 실행을 기록했다.

## 환경 및 안전성

평가 DB `woori_blog_agent_eval`과 운영 DB `woori_blog_agent`는 별도였다. 운영 identity role의 읽기 권한 제한을 확인했고, 운영 DB 데이터는 변경하지 않았다. 실행 후 로컬 llama.cpp `/health` 및 `/props`는 200을 반환했고, PID 39500은 Vulkan, 4 threads, 20 GPU layers 설정의 기본 Qwen3 4B였다. 모델 파일 SHA가 manifest와 일치했다. 후보는 기본 설정으로 남아 있지 않다.

평가 quota 종료 값: en 6/10, ko 4/10, ja 3/10, zh-CN 2/10. quota를 초기화하지 않았다. 유료 AI/API 호출 0, Blogger 운영 쓰기 0, 사람 검토 완료 0, 발행 준비 false. 기존 유료 호출·Blogger 쓰기 차단 유지.
