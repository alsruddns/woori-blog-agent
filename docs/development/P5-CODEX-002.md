## 실행 범위와 차단 사유

이 기록은 기존 P5-CONTENT-002 패키지, P5-AI-002 Qwen3 원고와 품질 기록, P5-AI-003 분석, P5-CODEX-001 사전 점검, 그리고 공식 원문을 확인한 사전 검토 결과다. 사용자가 이번 턴에 지정한 GPT-6 Luna High로 세션 모델을 바꾸거나 그 모델임을 확인하는 기능은 현재 세션에서 제공되지 않았다. ChatGPT Plus 포함 사용량만 쓰고 유료 크레딧은 쓰지 말라는 조건도 계정별 크레딧 잔액/사용 허용 상태를 읽을 수 있는 경로가 확인되지 않아 실행 전제로 검증하지 못했다.

OpenAI 공식 안내에 따르면 Codex는 먼저 포함 사용량을 사용하고, 한도에 도달하면 계정에 사용 가능한 크레딧 잔액을 사용할 수 있다. 자동 재충전이 꺼져 있어도 이미 보유한 크레딧의 사용 가능 여부와 잔액은 별도 확인 항목이다. 이 프로젝트에 허용된 현재 세션에서 잔액을 확인하거나 GPT-6 Luna High로 전환하지 못했으므로 원고 생성을 요청하지 않았다. 하위 `codex exec`, API 키, 별도 API, 추가 크레딧, 다른 모델을 호출하지 않았다.

필요한 재개 조건:

1. ChatGPT Settings → Usage에서 Codex에 적용되는 크레딧 잔액이 0이거나 크레딧 사용이 꺼져 있음을 사용자가 확인한다. 자동 재충전은 꺼진 상태를 유지한다.
2. 원고 작성 세션 자체가 GPT-6 Luna High로 설정되어 있음을 확인한다. Luna Medium/Low는 완성 기사 작성에 사용하지 않는다.
3. 확인 후 같은 조사 상태를 이어 받아 한 번에 한국어 1편과 영어 1편만 작성한다. 재조사나 반복 생성은 하지 않는다.
