# P5-CODEX-014 — 자동 운영 Dashboard 및 최종 통합 점검

## 결과 상태

**부분 완료: 읽기 전용 운영 현황 Dashboard와 브라우저 검증을 추가했습니다.** 콘텐츠 자동 생성·정기 수집 Worker·실제 Blogger Publisher는 구현·운영 확인이 되지 않았으므로 운영 자동화 완료로 보지 않습니다.

## 적용 내용

- 운영 홈을 수집, 원고 생성, 품질, 게시 상태와 예약 작업 현황을 한눈에 보는 한국어 화면으로 정리했습니다.
- 보호된 `GET /admin/operations/dashboard`가 현재 DB의 읽기 전용 상태를 요약합니다. 인증 없는 요청은 거부합니다.
- Google Trends Worker는 비활성, 시장 마감 및 주간 금융 작업은 미설정, 외부 GPT 예약 작업은 상태 확인 불가로 각각 표시합니다.
- 블로그별 OAuth 등록·scope 확인 시각·설정 모드·게시 제한과 Mock 결과를 분리합니다. 실제 Auto와 Blogger 쓰기는 비활성으로 고정되며, 공개 URL이 저장되지 않은 경우 URL을 만들어내지 않습니다.
- 수집원/연결 오류는 오류 원문 대신 오류 존재 여부만 반환해 토큰이나 응답 내용이 Dashboard에 노출되지 않도록 했습니다.
- Search Console이 연결되지 않았다는 점과 게시 URL·생성 Provider가 준비되지 않은 사실을 명시합니다.
- P5-UI-003의 기존 원고·Import·발행 화면과 경로를 유지했습니다. 이번 변경은 운영 홈 및 상태 API, 반응형 브라우저 검증으로 한정했습니다.

## 실제 운영 준비 상태

| 영역 | 확인된 상태 |
|---|---|
| Google Trends | 수집 기능/자료와 주기 실행 Worker를 구분합니다. Worker 실행은 확인되지 않았습니다. |
| GPT 예약 작업 | 로컬 서비스가 외부 예약 실행 상태를 확인할 수 없습니다. 원고 자동 전달은 미검증입니다. |
| 원고 생성 | 운영용 자동 생성 Provider가 연결되지 않았습니다. 수동 Import 흐름은 기존 기능입니다. |
| 국가별 장마감·금요일 금융 | 실행 Worker 및 데이터/원고 경로가 구성되지 않았습니다. |
| 블로그 상태 | 등록 정보와 OAuth scope/접근 확인 기록을 표시합니다. 계정 신원 또는 현재 접근성을 추정하지 않습니다. |
| Blogger 게시 | 실 Publisher/Auto가 비활성입니다. 이전 게시 작업의 Mock 상태와 실제 게시 기록을 별도로 표시합니다. |
| 게시 URL | DB에 연결 가능한 공개 URL이 없으면 표시 불가로 처리합니다. |
| 게시량 제한 | 저장된 일일 제한 및 최소 간격을 보여줍니다. 시간당 제한은 설정되지 않은 값으로 표시합니다. |
| 검색 성과 | Search Console 미연결로 노출·클릭·순위 수치를 표시하지 않습니다. |
| 서버 실행 | 기존 Windows 관리 스크립트를 유지합니다. 이 검증을 위해 띄운 API는 종료했으며, 사전에 실행 중이던 13100/18100은 건드리지 않았습니다. |

## 검증 및 안전

- 읽기 전용 API 테스트는 테스트 DB에서 상태 응답, 인증, 자동 게시 차단, 외부 예약 상태 미확인, Search Console 미연결과 데이터 카운트 보존을 확인합니다.
- Playwright는 운영 홈의 실제 브라우저 렌더링을 320, 390, 768, 1280, 1920px에서 확인합니다. 모바일/데스크톱 스크린샷은 `docs/development/assets/P5-CODEX-014-home-390.png`, `docs/development/assets/P5-CODEX-014-home-1280.png`에 저장합니다.
- 이번 작업에서 운영 DB 쓰기/마이그레이션, Blogger API 쓰기, 유료 AI API 호출은 수행하지 않았습니다.
- 기존 P5-UI-003의 상세 편집·승인 E2E는 이번에 재실행하지 않았으며, 이번 Playwright 범위는 운영 홈입니다.

## 사용 전 필요한 작업

1. 운영 환경에 적합한 DB 백업·복구 점검을 마치고 미적용 마이그레이션을 별도 승인 절차로 검토합니다.
2. 공식적이고 허용된 원고 생성/수신 경로를 준비합니다. GPT 예약 작업의 로컬 전달은 현재 미검증이므로 JSON Import를 수동 대체 경로로 사용합니다.
3. Blogger 쓰기 OAuth 및 Publisher 구현·오류 복구·실제 게시 URL 검증을 별도 검증합니다.
4. 별도 승인 후에만 운영 DB 변경이나 첫 Blogger 게시를 시험합니다. 이 변경만으로 Auto를 활성화하지 않습니다.
