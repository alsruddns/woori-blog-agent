## Changes

- Added six lifecycle states: proposed, planned, approved, enacted, paid, unverified. Facts default to unverified. A stronger state requires an explicit reviewed value and an exact supporting excerpt inside that fact; the model cannot promote status. The staged validator conservatively blocks detected lifecycle escalation. This lexical check does not certify meaning.
- The existing fact-first pipeline passes per-fact status, status rules and the section outline to the provider. The local prompt forbids internal fact labels, IDs and UUIDs, requires readable section structure, and directs independent paraphrase.
- Added `no_internal_fact_markers` to section and article quality checks. Citation, fact, direct-copy and human review gates remain active; no threshold was lowered.
- Restored written Chinese/Korean date recognition, ROC-to-Gregorian normalization and calendar-date validation. Regression tests include `115年7月1日 = 2026-07-01` and inherited-year Korean dates.
