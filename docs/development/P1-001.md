## 발견한 문제 및 해결
- 127.0.0.1 관리자 접속에 pgpass가 적용되지 않음: localhost로 연결해 해결.
- setuptools 모노레포 패키지 자동 탐색 실패: services/api 명시.
- PowerShell 파이프 인코딩으로 한글 손상: UTF-8 출력 설정 후 AGENTS/화면 복구 및 실제 HTTP 한글 검증.
- Pydantic 환경 설정 mypy 오탐: 공식 Pydantic 플러그인 적용.
- Next 초기 타입 검사에서 CSS/Node 선언 누락: 선언 파일 및 types 명시 후 검증.
- npm 명령을 루트에서 실행할 때 package.json 없음: 루트 위임 스크립트 추가.
