## Safe priority design (not activated)

Fed and SEC currently share the same English quota. Two explicit Fed runs occupied both slots early in the KST day, leaving no capacity for SEC. The limit need not increase to prioritize SEC:

1. Register a finite evaluation plan with an approved SEC English target as a one-slot reservation within the existing limit of 2.
2. Count active reservations against available capacity when admitting lower-priority evaluation plans; allow at most one non-reserved English run while the SEC plan is pending.
3. Consume the reservation only by creating the ordinary quota-counted target. Failed/held targets remain counted. Release an unused reservation only through an audited explicit cancellation/expiry rule; never reset consumed targets.
4. Use a stable idempotency key derived from the evaluation plan, evidence revision digest, target profile, model, prompt version, and pipeline version. A deliberate repeat requires a new explicit plan ID and consumes another normal slot.
5. Enforce the same pause/resource/concurrency and evaluation-DB isolation gates. No unbounded scheduler or quota increase is introduced.

This is a documented design only. No reservation table, limit, or scheduling behavior was changed in this phase.
